# 睡前流水帳口說練習

## 這是什麼

使用者額外自訂的口說練習習慣（非 SKILL.md 標準流程的一部分）：每天睡前用 1–3 分鐘
的份量，打字（或語音轉文字）跟 Claude 用英文分享當天發生的事，不用事先準備、
保留原本講話的填充詞和停頓，越接近真實口說越好。

## Claude 評估格式

沿用 `references/scoring-rubrics.md` 的 Speaking — Interview 評分維度
（Fluency / Intelligibility / Language Use / Organization），但額外加一段：

1. **分數 + CEFR 等級**
2. **優點**
3. **需改進**（特別留意跨句／跨段落才會出現的固定模式，例如時態一致性——
   這種問題在短版結構化題目中不容易被抓到）
4. **具體文法錯誤表**（原文 → 修正 → 說明）
5. **詞彙與片語升級表**（原文 → 更精準/更道地的說法 → 為什麼更好）
   —— 這欄位重點不是「你錯了」，而是「母語者在這個情境下更常怎麼講」，
   針對語意正確但選詞籠統、直翻中文、或搭配不夠道地的地方提供替代方案
6. **改進建議**（1–2 個具體可執行的練習方法）
7. **模範回答參考**（挑一段內容重寫成更自然的版本，不用整篇重寫）

## 記錄方式

每次練習後，把摘要記到 `progress.json` 的 `daily_log`，
`section: "speaking"`，`note` 欄位記錄當次抓到的主要優缺點模式，
方便之後追蹤是否有進步或反覆出現同樣的問題。這是額外練習，
不會覆蓋 `baseline_scores` / `latest_scores`（那些只由正式診斷測驗
或模擬考更新）。
