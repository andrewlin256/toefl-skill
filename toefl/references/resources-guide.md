| 工具 | 費用 | 說明 |

| **ELSA Speak** | 免費版可用 | 發音矯正 AI，音素級別分析 |
| **SpeechAce** | 免費試用 | 發音評分 API |
| 本系統 `speaking_coach.py` | 免費 | 產生題目 + Claude 評估 |
| 手機錄音 App | 免費 | 錄音後自己回聽或傳給 Claude |

### 口說練習法
1. **Shadowing（跟讀）：** 聽 TED-Ed → 暫停 → 立即複述 → 對比
2. **即興回答：** 用 speaking_coach.py 產生題目 → 計時 45 秒 → 錄音
3. **回聽分析：** 聽自己的錄音，檢查停頓、文法、時間控制
4. **Claude 評估：** 把文字版回答貼給 Claude，依 rubric 評分

## 8. 開源工具鏈（本系統使用）

| 工具 | 用途 | 安裝指令 |
|------|------|----------|
| `edge-tts` | 免費 TTS（Microsoft Edge 語音） | `pip install edge-tts` |
| `genanki` | Python Anki deck 產生器 | `pip install genanki` |
| `Kokoro TTS` | 離線高品質 TTS（82M 參數） | `pip install kokoro` |
| `Piper TTS` | 超輕量離線 TTS（可跑在 RPi） | 見 GitHub |

### edge-tts 推薦語音
| 語音 | 代碼 | 用途 |
|------|------|------|
| Aria (女) | `en-US-AriaNeural` | 旁白、一般素材 |
| Guy (男) | `en-US-GuyNeural` | 教授、學術演講 |
| Jenny (女) | `en-US-JennyNeural` | 女學生角色 |
| Tony (男) | `en-US-TonyNeural` | 男學生角色 |
| Sara (女) | `en-US-SaraNeural` | 公告、正式通知 |
| Sonia (女) | `en-GB-SoniaNeural` | 英式口音練習 |

```bash
# 列出所有可用語音
edge-tts --list-voices | grep en-

# 產生音檔
edge-tts --voice en-US-AriaNeural --text "Hello world" --write-media hello.mp3

# 調整語速（模擬不同難度）
edge-tts --rate=-20% --voice en-US-GuyNeural --text "..." --write-media slow.mp3   # 慢速 Lv1-2
edge-tts --rate=+0%  --voice en-US-GuyNeural --text "..." --write-media normal.mp3 # 正常 Lv3
edge-tts --rate=+15% --voice en-US-GuyNeural --text "..." --write-media fast.mp3   # 快速 Lv4-5
```

## 11. 每週素材排程建議

自適應引擎（adaptive.py）會根據分數調整，但以下是基礎排程：

### 基礎期（Week 1-4）
| 日 | 聽力素材 | 閱讀素材 | 口說 | 寫作 |
|----|----------|----------|------|------|
| 1 | VOA 1篇 | Wikipedia Simple 1篇 | — | — |
| 2 | BBC 6min 1集 | — | 跟讀 TED-Ed 1支 | — |
| 3 | — | Nat Geo 1篇 | — | Build a Sentence 10題 |
| 4 | TED-Ed 1支 | — | Interview 2題 | Email 1篇 |
| 5 | BBC 1集 | The Conversation 1篇 | — | — |
| 6 | — | — | 跟讀 15min | Discussion 1篇 |

### 強化期（Week 5-8）
- 聽力升級：NPR Short Wave → 60-Second Science
- 閱讀升級：Scientific American 短文
- 口說：每天 shadowing 15 分鐘
- 寫作：每兩天一篇，Claude 批改

### 衝刺期（Week 9-12）
- 聽力：模擬考音檔，只聽一次
- 閱讀：限時練習
- 口說：完整模擬（7 repeat + 4 interview）
- 寫作：計時完成全部三種題型

## ⚠️ 避免使用的資源

| 類型 | 原因 |
|------|------|
| 2025 年或更早的 TOEFL 練習書 | 題型完全不同（沒有 Listen & Repeat、Email 等） |
| 未標明「2026 format」的線上練習 | 可能是舊制題目 |
| 非授權的 TPO 外流版本 | 品質不穩定，可能有錯誤 |
| 純機器翻譯的素材 | 文法和用詞可能不自然 |
| 只練模板的備考書 | 2026 AI 評分會偵測模板並扣分 |
